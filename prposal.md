# Financial Sentiment Analysis Using News Headlines

## Project Description

In this project, I aim to analyze the relationship between financial news sentiment and stock market movements. Instead of focusing only on stock prices, this project explores how human-generated information (news headlines) may influence market behavior.

The dataset used in this project is the **"Daily News for Stock Market Prediction"** dataset from Kaggle. It contains historical news headlines collected from Reddit (WorldNews) along with the Dow Jones Industrial Average (DJIA) stock index movements.

## Motivation

Financial markets are not driven only by numbers but also by human emotions, expectations, and reactions to news. Understanding this relationship can provide valuable insights into market behavior.

## Research Question

Is there a statistically significant relationship between the sentiment of daily news headlines and stock market movements?

## Methodology

- Data cleaning and preprocessing
- Sentiment analysis using NLP techniques (TextBlob)
- Exploratory Data Analysis (EDA)
- Hypothesis testing (correlation analysis)
- Machine learning models (Decision Tree, Random Forest)

## Expected Outcome

This project aims to determine whether news sentiment has predictive power over stock market direction and to evaluate the effectiveness of machine learning models in this context.
